# SQL Practice Lab

Browser-based SQL practice site. Open `index.html` in a browser (needs internet once to load the sql.js engine).

- Free SQL editor over HR, sailor and lab tables
- Assignment bank: customer DDL/DML, HR basics, constraints, sailors joins/sets, HR group-by, sub-queries
- Each question: Show answer, Run answer, Load in editor
- Reset database restores the seed data

Files:
- `index.html` - the full site (seed data embedded)
- `template.html` - page source with a seed placeholder
- `seed_all.sql` - SQLite seed (HR schema and data, sailor/boat/reserve tables)
